# استودیو هنر دیجیتال (Digital Art Studio)

ویرایشگر تصویر و نقاشی لایه‌ای در مرورگر (React + TypeScript + Vite) با ابزارهای شبیه Photoshop،
پشتیبانی از قلم نوری و شبیه‌سازی فشار برای موس (Velocity Pressure).

## اجرا

```bash
npm install
npm run dev      # توسعه
npm run build    # typecheck + build
npm run lint     # oxlint
npm test         # تست‌های واحد (History / Fill / Selection)
```

## ابزارها و میانبرها (بر اساس کلید فیزیکی؛ با کیبورد فارسی هم کار می‌کند)

| کلید | ابزار | کلید | ابزار |
|---|---|---|---|
| B | قلم‌مو | G | سطل رنگ / گرادیان |
| E | پاک‌کن | S | Clone Stamp |
| V | Move | R / O | Smudge / Dodge-Burn |
| M / L / W | Marquee / Lasso / Magic Wand | P | Pen |
| C | Crop | T | متن |
| I | Eyedropper | U | شکل |
| H / Z | Hand / Zoom | `[` `]` | کوچک/بزرگ کردن قلم |

- `Ctrl+Z` بازگشت · `Ctrl+Y` یا `Ctrl+Shift+Z` جلو · `Ctrl+S` دانلود PNG (اندازهٔ واقعی سند)
- `Ctrl+D` / `Esc` لغو انتخاب · `Delete` پاک‌کردن محتوای ناحیهٔ انتخاب‌شده
- `+` `-` `0` زوم / تناسب با صفحه · `Space` + درگ = جابه‌جایی نما
- `Alt+کلیک` در Clone Stamp = تعیین منبع · روی دستگاه لمسی، نگه‌داشتن دکمهٔ ابزار = زیرابزارها

## رفتارها

- Undo/Redo کامل است: پیکسل‌ها، جابه‌جایی/تغییر اندازه/چرخش، افزودن/حذف/ترتیب لایه‌ها (سقف حافظه ≈ ۳۰۰MB).
  پس از Crop تاریخچه پاک می‌شود.
- تغییر اندازه/چرخش لایه تا زمانی که روی همان لایه نقاشی نکنید غیرمخرب است؛ با اولین ابزار نقاشی در پیکسل‌ها اعمال می‌شود.
- انتخاب‌ها (Marquee / Lasso / Wand و ترکیب Add/Subtract/Intersect) روی همهٔ ابزارهای نقاشی و پر کردن اعمال می‌شوند.
- حداکثر ابعاد سند ۸۰۰۰ پیکسل و ۳۶ مگاپیکسل است (محدودیت بوم مرورگرها).
